# Data

Put `heart_attack.csv` here (129,998 rows, 16 columns). It is a subset of the CDC's
Behavioral Risk Factor Surveillance System (BRFSS) 2015 survey, as published in the
[Heart Disease Health Indicators dataset](https://kaggle.com/datasets/alexteboul/heart-disease-health-indicators-dataset).

The CSV is not committed to the repository. Download it from the source above.
